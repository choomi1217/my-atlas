# PRD — 실시간 1:1 채팅 (정상 문서)

> 문서 유형: 정상 PRD (명확·완결)
> 용도: Test Studio 입력 테스트 — 잘 정의된 요구사항으로부터 TC가 온전히 생성되는지 확인
> 대상 기능: 메신저 앱의 1:1 채팅

---

## 1. 개요

사용자가 친구와 실시간으로 1:1 텍스트 메시지를 주고받는 기능이다. 메시지는 전송 즉시 상대에게 전달되며, 읽음 여부와 전송 상태를 표시한다.

## 2. 목표

- 지연 없는 실시간 메시지 송수신 (평균 1초 이내 전달)
- 전송 실패 시 재시도 및 사용자 인지
- 오프라인 상대에게도 메시지 보관 후 접속 시 전달

## 3. 사용자 스토리

1. 사용자는 친구 목록에서 상대를 선택해 채팅방에 진입한다.
2. 사용자는 텍스트를 입력하고 전송 버튼을 눌러 메시지를 보낸다.
3. 사용자는 상대가 메시지를 읽었는지 확인한다.
4. 사용자는 과거 대화 내역을 위로 스크롤해 조회한다.

## 4. 기능 요구사항

| ID | 요구사항 |
|----|----------|
| FR-1 | 채팅방 진입 시 최근 30개 메시지를 최신순으로 로드한다. |
| FR-2 | 메시지 전송 시 즉시 "전송 중" 상태로 표시하고, 서버 확인 후 "전송 완료"로 전환한다. |
| FR-3 | 상대가 메시지를 열람하면 해당 메시지에 "읽음" 표시를 노출한다. |
| FR-4 | 위로 스크롤 시 이전 30개 메시지를 추가 로드(페이지네이션)한다. |
| FR-5 | 텍스트 메시지는 최대 2,000자까지 입력 가능하다. |
| FR-6 | 상대가 오프라인이면 메시지를 서버에 보관하고, 상대 접속 시 전달한다. |

## 5. 비기능 요구사항

- 메시지 전달 지연: 정상 네트워크 기준 평균 1초 이내
- 동시 접속: 한 채팅방에 두 사용자 동시 입력 처리
- 보안: 전송 구간 TLS 암호화

## 6. 예외 / 에러 처리

| 상황 | 처리 |
|------|------|
| 네트워크 끊김 중 전송 | "전송 실패" 표시 + 재전송 버튼 노출 |
| 2,000자 초과 입력 | 초과분 입력 차단 + "최대 2,000자" 안내 |
| 빈 메시지 전송 시도 | 전송 버튼 비활성화 |
| 차단된 사용자에게 전송 | "메시지를 보낼 수 없습니다" 안내 |

## 7. 범위 밖 (Out of Scope)

- 이미지/파일 첨부 (별도 PRD)
- 그룹 채팅
- 음성/영상 통화
