# Test Studio 입력 테스트 데이터

Test Studio(문서 → TC 자동 생성)에 투입해 동작을 확인하기 위한 **입력 문서 샘플**이다.

| 파일 | 용도 |
|------|------|
| `입력문서_1_정상PRD_챗.md` | 명확·완결된 PRD → TC가 온전히 생성되는지 |
| `입력문서_3_모호한문서_챗.md` | 의도적으로 모호한 문서 → 무리한 TC 대신 질문/불명확 지적이 나오는지 |
| `입력문서_4_긴문서_챗.md` | 다기능·대용량 문서 → 여러 기능에 걸쳐 누락 없이 TC가 생성되는지 |

> 파일명은 **유니코드 NFC(조합형)** 로 저장되어 있어 Notion 등에 업로드해도 한글이 깨지지 않는다.
> (macOS의 NFD 분해형 파일명을 Notion이 raw로 표시해 깨지던 이슈 대응.)
> 원본 분실로 2026-07-20 재작성한 샘플이며, 실제 기능 명세가 아니라 **테스트용 픽스처**다.
