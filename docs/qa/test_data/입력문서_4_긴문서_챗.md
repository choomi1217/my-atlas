# PRD — 통합 메시징 플랫폼 (긴 문서)

> 문서 유형: 대용량/다기능 PRD
> 용도: Test Studio 입력 테스트 — 긴 문서에서 다수 기능에 걸쳐 TC가 누락 없이 생성되는지 확인
> 대상: 1:1 채팅 + 그룹 채팅 + 파일 전송 + 알림 + 검색 + 관리자

---

## 1. 개요

본 문서는 메신저 서비스의 핵심 메시징 경험 전반을 정의한다. 1:1/그룹 채팅, 파일 전송, 푸시 알림, 메시지 검색, 관리자 모더레이션까지 포함한다.

## 2. 용어

| 용어 | 정의 |
|------|------|
| 채팅방 | 둘 이상의 사용자가 메시지를 주고받는 논리적 공간 |
| 멤버 | 채팅방에 참여 중인 사용자 |
| 방장 | 그룹 채팅방을 생성했거나 권한을 위임받은 멤버 |
| 관리자(Admin) | 서비스 전체를 운영하는 운영자. 신고 처리·계정 제재 권한 보유 |

---

## 3. 기능 A — 1:1 채팅

### 3.1 요구사항
| ID | 내용 |
|----|------|
| A-1 | 친구 목록에서 상대 선택 시 채팅방 진입, 최근 30개 메시지 로드 |
| A-2 | 전송 상태(전송 중 / 완료 / 실패) 표시 |
| A-3 | 읽음 표시 |
| A-4 | 위로 스크롤 시 이전 메시지 30개 추가 로드 |
| A-5 | 텍스트 최대 2,000자 |

### 3.2 예외
- 네트워크 끊김 중 전송 → 전송 실패 + 재전송
- 차단된 상대에게 전송 → 차단 안내

---

## 4. 기능 B — 그룹 채팅

### 4.1 요구사항
| ID | 내용 |
|----|------|
| B-1 | 방장은 멤버를 초대/강퇴할 수 있다 (최대 100명) |
| B-2 | 방 제목·공지 설정 가능 |
| B-3 | 멤버는 방을 나갈 수 있고, 방장이 나가면 권한이 다음 멤버에게 위임된다 |
| B-4 | 메시지에 @멘션 시 해당 멤버에게 별도 알림 |

### 4.2 예외
- 100명 초과 초대 시도 → 초대 차단 + 안내
- 방장 강퇴 시도 → 불가 (방장은 위임 후에만 퇴장)

---

## 5. 기능 C — 파일 전송

### 5.1 요구사항
| ID | 내용 |
|----|------|
| C-1 | 이미지/문서 첨부 (개당 최대 20MB) |
| C-2 | 이미지 썸네일 미리보기 |
| C-3 | 업로드 진행률 표시 |
| C-4 | 다운로드 및 재전송 |

### 5.2 예외
- 20MB 초과 → 업로드 거부 + 안내
- 지원하지 않는 형식 → 거부
- 업로드 중 취소 → 부분 업로드 폐기

---

## 6. 기능 D — 푸시 알림

| ID | 내용 |
|----|------|
| D-1 | 앱 미실행/백그라운드 시 새 메시지 푸시 알림 |
| D-2 | 방별 알림 on/off 설정 |
| D-3 | 방해 금지 시간대 설정 (해당 시간엔 알림 억제) |
| D-4 | 멘션은 방 알림이 off여도 알림 발송 |

---

## 7. 기능 E — 메시지 검색

| ID | 내용 |
|----|------|
| E-1 | 방 내 텍스트 키워드 검색 |
| E-2 | 검색 결과에서 해당 메시지로 이동 |
| E-3 | 전체 방을 가로지르는 통합 검색 |

---

## 8. 기능 F — 관리자 모더레이션

| ID | 내용 |
|----|------|
| F-1 | 사용자는 메시지를 신고할 수 있다 |
| F-2 | 관리자는 신고 목록을 조회·처리한다 |
| F-3 | 관리자는 계정을 일시 정지/영구 정지할 수 있다 |
| F-4 | 정지된 계정은 메시지를 보낼 수 없다 |

---

## 9. 비기능 요구사항

- 메시지 전달 지연: 평균 1초 이내
- 검색 응답: 500ms 이내 (방 내 검색 기준)
- 동시성: 그룹 방 100명 동시 활동 처리
- 보안: 전송 구간 TLS, 첨부 파일 접근 권한 검증
- 가용성: 월 99.9%
