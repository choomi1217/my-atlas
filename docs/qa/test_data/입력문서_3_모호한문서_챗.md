# 기획 메모 — 채팅 개선 (모호한 문서)

> 문서 유형: 모호/불완전 문서 (의도적)
> 용도: Test Studio 입력 테스트 — 요구사항이 모호할 때 무리한 TC 생성 대신 질문/불명확 지적이 나오는지 확인
> 주의: 이 문서는 일부러 불명확하게 작성되었다.

---

채팅 좀 더 좋게 만들자.

- 메시지가 너무 느린 것 같음. 빠르게 해야 함.
- 알림이 안 오는 경우가 있다는데 확인 필요.
- 관리자는 아무거나 다 볼 수 있어야 하고, 일반 유저는 적당히 제한.
- 오래된 메시지는 알아서 정리.
- 이모지 같은 것도 되면 좋고.

메시지 보관 기간은 상황에 따라 다르게. 중요한 건 오래 두고, 아니면 짧게.

권한은 기존이랑 비슷하게 가되, SuperUser 개념을 새로 넣을 수도 있음 (admin이랑 겹치는지는 나중에 정리).

성능 목표는 "충분히 빠르게".
